E-commerce shopping: high-level design, AWS with Azure equivalents

A typical online store: product catalog, search, cart, checkout, payment, inventory, orders, recommendations and notifications. Every component shows the AWS service and its Azure equivalent. An optional shopping concierge agent sits beside the core store.

  • Reads are cheap: catalog and search pages are served from the edge and Redis; only cart and checkout calls hit the database every time.
  • Checkout is a saga: each step (reserve, charge, confirm) has a compensating step (release, refund, cancel), so a failure never leaves stock held or a card charged without an order.
  • Agent is optional and fenced: the concierge only proposes bundles; prices, stock and compatibility are re-checked in code before the shopper sees the package.
